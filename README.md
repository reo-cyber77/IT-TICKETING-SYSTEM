# IT-TICKETING-SYSTEM
A Windows Forms IT ticketing system with separate Employee and IT Support dashboards, ticket tracking, department selection, and text-file-managed support accounts.



For non-technical users, upload a ready-to-run app ZIP to a GitHub Release. Don’t rely on Code → Download ZIP—that downloads the source project.
1. In Visual Studio, right-click TicketDesk in Solution Explorer and select Publish.
2. Choose Folder as the target. Set deployment to Self-contained and runtime to win-x64, then publish.
3. Put support_accounts.txt beside TicketDesk.exe in the published folder. It’s needed for IT Support sign-in.
4. Zip the published folder.
5. On GitHub, open the repository’s Releases section, choose Create a new release, and attach the ZIP.
6. Users download the ZIP from the release’s Assets, extract it, and open TicketDesk.exe.
Keep only demo credentials in any files you upload publicly. Don’t include real passwords or private ticket data.
