# IT-TICKETING-SYSTEM
A Windows Forms IT ticketing system with separate Employee and IT Support dashboards, ticket tracking, department selection, and text-file-managed support accounts.



How to Run the IT Ticketing System
1. Open our GitHub repository.
2. Go to Releases and download the latest TicketDesk ZIP.
3. Right-click the ZIP and select Extract All.
4. Open the extracted folder and double-click TicketDesk.exe.
5. Choose Employee or IT Support, then sign in using the demo account details provided by the group.
Keep support_accounts.txt in the same folder as TicketDesk.exe. Don’t move or delete it; the app uses it to check IT Support accounts.
